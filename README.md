# Slipspace — Android App

The Android app for [slipspace.me](https://slipspace.me). This repo exists for one
reason: so you can always grab the latest build from a fixed place.

## Installing

The app isn't on the Play Store, so Android will ask before installing it.

1. Download `slipspace.apk` on your phone.
2. Open it. Android will warn that it came from an unknown source — allow it for
   your browser or file manager when prompted.
3. Install, then open Slipspace and sign in as usual.

Updating works the same way: download the new APK and install over the top. Your
account, spaces, and settings live on the server, so nothing is lost.

## What's in this build

- **File downloads.** Tapping a file in chat now downloads it — it lands in your
  Downloads folder with a notification. Previously nothing happened.
- **Download confirmation.** Tapping a file asks first and shows its name and size.

## Good to know

- The app is a thin shell around the live site, so most updates reach you the
  moment you reopen it — no new APK needed. You only need to reinstall when this
  page says so.
- If something looks stale, fully close the app (swipe it away from recents) and
  reopen it. That's the app's version of a hard refresh.
- Builds here are debug-signed for sideloading. If installing over an older copy
  ever fails, uninstall the old one first and reinstall.
